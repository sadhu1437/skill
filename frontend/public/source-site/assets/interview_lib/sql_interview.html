Top SQL Interview Questions

Preparing for an SQL interview? Here are some of the most common SQL interview questions along with their answers, suitable for both freshers and experienced candidates. Understanding these concepts will help you demonstrate your SQL skills effectively during interviews.

1. What is SQL?

SQL (Structured Query Language) is a standard programming language used for managing and manipulating relational databases. It allows users to perform various operations such as querying data, updating records, and managing database structures.

2. What are the different types of SQL commands?

  • DML (Data Manipulation Language): Commands like SELECT, INSERT, UPDATE, and DELETE that are used to manipulate data in the database.
  • DDL (Data Definition Language): Commands like CREATE, ALTER, and DROP that define and modify database structures.
  • DCL (Data Control Language): Commands like GRANT and REVOKE that control access to data in the database.
  • TCL (Transaction Control Language): Commands like COMMIT, ROLLBACK, and SAVEPOINT that manage transactions in the database.

3. What is a primary key?

A primary key is a unique identifier for a record in a database table. It ensures that each record can be uniquely identified and cannot contain NULL values. A table can have only one primary key, which may consist of a single or multiple columns.

4. What is the difference between INNER JOIN and OUTER JOIN?

INNER JOIN: Returns only the rows that have matching values in both tables. OUTER JOIN: Returns all rows from one table and the matched rows from the other table. If there is no match, NULL values are returned for the columns of the table without a match. Types include LEFT, RIGHT, and FULL outer joins.

5. What is normalization?

Normalization is the process of organizing data in a database to reduce redundancy and improve data integrity. It involves dividing large tables into smaller, related tables and defining relationships between them. The main goals of normalization are to eliminate duplicate data and ensure data dependencies are properly enforced.

6. What are indexes in SQL?

Indexes are database objects that improve the speed of data retrieval operations on a table. They work like a book's index, allowing the database engine to find rows more quickly. However, indexes can slow down data modification operations (INSERT, UPDATE, DELETE) because the index must also be updated.

7. What is a foreign key?

A foreign key is a field (or a collection of fields) in one table that uniquely identifies a row in another table. It establishes a relationship between the two tables, enforcing referential integrity. A foreign key in a child table points to a primary key in a parent table.

8. What is a stored procedure?

A stored procedure is a precompiled collection of one or more SQL statements that can be executed as a single unit. Stored procedures are used to encapsulate complex business logic, improve performance, and enhance security by controlling access to data.

9. What is the difference between HAVING and WHERE clauses?

The WHERE clause is used to filter records before any groupings are made, while the HAVING clause is used to filter records after groupings have been made (usually used with the GROUP BY clause and aggregate functions).

10. What is a view in SQL?

A view is a virtual table that is based on the result of a SELECT query. It does not store data physically but provides a way to present data from one or more tables in a specific format. Views can simplify complex queries and enhance security by restricting access to specific data.

11. What is the difference between DELETE, TRUNCATE, and DROP?

DELETE: A DML command used to remove specific rows from a table based on a WHERE condition. It can be rolled back. TRUNCATE: A DDL command that removes all rows from a table instantly, freeing up space. It is faster than DELETE and generally cannot be rolled back. DROP: A DDL command that completely removes the table structure and its data from the database.

12. What are ACID properties in a database?

ACID is an acronym for Atomicity, Consistency, Isolation, and Durability. These properties guarantee that database transactions are processed reliably. Atomicity ensures the transaction is all or nothing. Consistency ensures data remains valid. Isolation ensures concurrent transactions do not interfere with each other. Durability ensures the results of a committed transaction are permanently saved.

13. What is the difference between UNION and UNION ALL?

Both commands combine the result sets of two or more SELECT statements. The difference is that UNION removes duplicate rows from the final result set, which adds processing overhead. UNION ALL includes all duplicates and is generally faster because it does not have to scan for and remove identical rows.

14. What is a Subquery?

A subquery (or nested query) is a query within another SQL query. It is typically embedded within the WHERE, HAVING, or FROM clause of the main query. The subquery executes first, and its output is used by the main (outer) query to filter or evaluate data.

15. What is a Database Trigger?

A trigger is a special type of stored procedure that automatically executes (or "fires") in response to certain events on a particular table or view. These events are usually DML operations such as INSERT, UPDATE, or DELETE. Triggers are commonly used to maintain audit trails or enforce complex business rules automatically.
