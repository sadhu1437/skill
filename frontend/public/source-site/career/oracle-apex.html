Job Code: JI-21390

IT Fresher - Oracle APEX

JTEKT India Limited - Advancing Manufacturing with Digital Innovation

Location: Jaipur - Delhi Expressway | Application Expires: 30 Sept 2026

Drive Overview

JTEKT India Limited, a globally renowned automotive and manufacturing giant, is rapidly digitizing its enterprise operations. We are looking for an ambitious IT Fresher specializing in Oracle APEX to join our high-performing technology team. In this role, you will bridge the gap between complex Oracle backend logic (EBS) and modern, user-friendly frontend applications. If you have a solid grounding in SQL/PLSQL and a passion for low-code/high-impact platforms, this role offers an excellent entry into enterprise digital transformation.

Compensation ₹5.20L - ₹5.25L P.A.
Experience Level 0 - 1 Years
Primary Domain Oracle & PL/SQL

Your Role & Responsibilities

You will play a pivotal role in accelerating JTEKT's process automation initiatives by designing robust APEX applications backed by the Oracle E-Business Suite (EBS).

  • APEX Development: Develop, test, and deploy applications using Oracle APEX (forms, reports, dashboards, workflows).
  • Requirements Engineering: Gather and analyze business requirements from cross-functional and manufacturing teams.
  • System Integration: Integrate APEX applications tightly with Oracle EBS and other external systems using REST APIs and web services.
  • Frontend Customization: Design user-friendly interfaces leveraging HTML, CSS, JavaScript, and jQuery.
  • Backend Optimization: Write robust SQL and PL/SQL for data manipulation, backend logic, and perform database performance tuning.
  • Support & Compliance: Troubleshoot technical issues, prepare technical documentation, follow coding standards, and support audit compliance.

Market Trend: Oracle APEX in Manufacturing

Enterprise manufacturing organizations are shifting towards low-code platforms to modernize their legacy Oracle databases. Oracle Application Express (APEX) is leading this charge, allowing developers to build fast, secure, and scalable web apps directly on top of Oracle Databases. As a fresher, mastering APEX along with deep PL/SQL logic puts you in a highly specialized, recession-proof niche within the ERP and IT Services ecosystem.

Required Skills & Qualifications

Oracle APEX PL/SQL & SQL Java Basics HTML / CSS / JS REST APIs Oracle EBS
  • Education: Minimum B.Tech in Information Technology (IT) or related computer science discipline.
  • Experience: 0 to 1 years (Freshers with strong academic/internship exposure are ideal).
  • Database Mastery: Strong knowledge in data modeling, database design, SQL, and PL/SQL.
  • Web Tech: Knowledge of HTML, CSS, JavaScript, and jQuery for customizing APEX UIs.
  • Security: Understanding of security practices including authentication, authorization, and data protection.
  • DevOps: Exposure to version control tools and deployment processes.

Expert Preparation Guide for JTEKT

1. Deep Dive into PL/SQL

Your backend logic is purely PL/SQL. Be prepared to write triggers, cursors, functions, and stored procedures on a whiteboard. Interviewers will heavily test your ability to handle exceptions and optimize complex SQL queries.

2. Oracle APEX Components

Familiarize yourself with the APEX workspace. You must be able to explain the difference between Page Items, Application Items, Dynamic Actions, and how APEX handles session state. Knowing how to consume a REST API within APEX is a massive plus.

3. Front-End Customization

While APEX is low-code, JTEKT expects you to use HTML, CSS, and JS/jQuery for UI customization. Be ready to explain how you would trigger a jQuery function on a specific APEX page event (like 'Page Load' or 'Change').

Recommended Extra Activities

  • Get a Free APEX Workspace: Sign up for a free workspace on apex.oracle.com. Build a simple CRUD application (e.g., an Employee Management System) to showcase during your interview.
  • Understand Oracle EBS: Read a brief overview of Oracle E-Business Suite (EBS) architecture. Knowing how APEX extends EBS functionality demonstrates high domain awareness.
