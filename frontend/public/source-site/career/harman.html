Associate Engineer - AI/ML

HARMAN Automotive - Transforming Tomorrow with Innovative Power

Location: Bangalore (Kalyani Platina) | Level: T2

⚠️ Office Requirement: You are expected to work all 5 days a week in the Bangalore office.

Drive Overview

We’re a global, multi-disciplinary team putting the innovative power of technology to work at HARMAN Automotive. We are giving fresh graduates and early-career professionals the keys to fast-track their careers. We are seeking a highly enthusiastic Agentic AI Engineer eager to work on next‑generation systems driven by autonomous agents and Large Language Models (LLMs). Advance in-vehicle infotainment, safety, efficiency, and enjoyment by building intelligent, scalable, and automated solutions.

Target Experience 0 - 1 Year / Fresher
Primary Stack Python, LLMs, GenAI
Work Mode On-site (5 Days)

Your Role & Impact

This is a pure-play AI engineering role. You will be dealing directly with large language models, embedding frameworks, and cloud-native backend development.

  • Agentic AI Workflows: Design and develop workflows using LLMs, tools, planners, and memory components.
  • LLM Integration: Build and integrate applications using frameworks such as LangChain and LlamaIndex.
  • Backend APIs: Develop robust RESTful APIs and microservices using Django, Flask, FastAPI, or Robyn Framework.
  • RAG Pipelines: Implement Retrieval Augmented Generation (RAG) pipelines using vector databases and embeddings.
  • Model Development: Handle feature engineering, data preprocessing, and ML model training using TensorFlow, PyTorch, or Scikit-learn.
  • Cloud & DevOps: Containerize applications using Docker and support CI/CD deployments on Kubernetes and AWS.

Market Trend: The Agentic AI Era

The tech industry is rapidly evolving from basic generative AI (like ChatGPT prompts) to Agentic AI. Automotive companies like HARMAN are using autonomous AI agents that can reason, plan, and execute multi-step tool calls to improve everything from in-car voice assistants to software diagnostics. By mastering RAG architectures and vector databases as an Associate Engineer, you position yourself in the highest-paying, most future-proof segment of software development.

Eligibility & Technical Requirements

Python (Mandatory) LangChain / LlamaIndex FastAPI / Django TensorFlow / PyTorch RAG & Vector DBs Docker
  • Education: Bachelor’s degree (or final‑year student) in Computer Science, AI/ML, Data Science, or a related field.
  • Experience: 0 to 1 year of experience. Strong academic/project exposure in AI, ML, or Software Development is accepted.
  • Programming: Mandatory programming knowledge in Python. Exposure to GoLang, Java, or JS is a plus.
  • AI/ML Basics: Basic understanding of NLP, Transformers, Large Language Models (OpenAI, LLaMA), and common ML algorithms.
  • Web Tech: Understanding of RESTful APIs, JSON, SQLAlchemy, HTML, CSS, and secure authentication (OAuth, JWT).

Expert Preparation Guide for HARMAN

1. Python & FastAPI Backend

Since you'll be deploying AI models, your backend must be fast. Practice building lightweight REST APIs using FastAPI or Flask. Understand how to handle asynchronous processing (using Celery, as mentioned in the JD).

2. Master the RAG Pipeline

RAG (Retrieval Augmented Generation) is the core of modern enterprise AI. Be ready to explain the pipeline: Data Ingestion → Chunking → Vector Embeddings → Vector Database Search → LLM Generation. Mentioning tools like Hugging Face or Pinecone will earn you massive bonus points.

3. Understand Autonomous "Agents"

What is "Agentic AI"? Prepare to explain how an LLM can use "Tools" (like a calculator or a web search function) to solve a problem it wasn't explicitly programmed for. Familiarize yourself with the concept of LLM Memory and Planners.

Recommended Extra Activities

  • GitHub Portfolio: HARMAN specifically asks for "personal GitHub projects." Ensure you have at least one repository demonstrating a LangChain or LlamaIndex implementation.
  • Dockerize an App: Take a simple Python ML model, wrap it in a Flask API, and write a Dockerfile for it. This proves you understand the deployment concepts they are looking for.
  • SkillBloom Resource: Download our "GenAI & RAG Interview Master Kit" from the PDF section for specialized LLM orchestration challenges.
