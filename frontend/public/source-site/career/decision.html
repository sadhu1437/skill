Drive Overview

Decisions is a fast-growing, private-equity-backed technology powerhouse specializing in Business Process Automation (BPA). Our no-code platform integrates rules engines and AI tools to help enterprises modernize legacy systems 3x faster than traditional coding. We are expanding our Mumbai Engineering hub and looking for passionate junior developers ready to launch their careers in the .NET and C# ecosystem. This is a rare opportunity to join a high-caliber team where you can contribute to production code within your first quarter.

Target Batch 2025 & 2026 Grad
Experience 0 - 1 Year
Primary Stack C# / .NET / React

What You Will Do & Learn

Decisions invests heavily in junior talent through structured onboarding and weekly learning sessions.

  • Development: Build and support business automation software using C# and ASP.NET MVC.
  • Frontend: Create modern, responsive user interfaces with React and HTML5.
  • DevOps: Gain hands-on exposure to Docker and agile deployment methodologies.
  • Requirement Analysis: Collaborate with product managers to translate complex rules into efficient logic.
  • Performance: Participate in performance testing, debugging, and continuous codebase improvement.
  • Mentorship: Receive direct guidance from senior engineers to master real-world SDLC practices.

Market Trend: The BPA Acceleration (2026)

The Business Process Automation market is projected to reach $30 Billion by 2030. Companies are moving away from rigid legacy software toward Low-Code/No-Code platforms that offer speed and flexibility. Joining Decisions allows you to build the core engine that powers these platforms. Developers with a strong grasp of C# and React in an automation context are currently among the highest-paid early-career professionals in the Mumbai tech corridor.

Decisions Selection Roadmap

1. Application & Project Screening

Shortlisting based on academic degree (CS/IT/Math) and evidence of hands-on software projects (Educational, personal, or portfolio).

2. Coding Assessment (C# or React)

A test evaluating your logic and proficiency in either C# fundamentals or React hooks. They look for clean code and problem-solving skills.

3. Technical Deep-Dive

Interview focusing on Object-Oriented Programming (OOP) concepts, database integration, and basic web architecture.

4. Engineering Manager Review

Discussion on cultural fit, your eagerness to learn, and your ability to manage priorities and deadlines.

Required Skills & Qualifications

C# / .NET React.js ASP.NET MVC OOP Principles JavaScript / HTML5 Docker (Basic)

Expert Preparation Guide for Decisions

1. Mastery of OOPs Concepts

Decisions' platform is heavily built on Object-Oriented logic. Master Inheritance, Polymorphism, Abstraction, and Encapsulation. Be ready to explain how these apply to real-world software design.

2. C# Fundamentals

Practice using LINQ, async/await, and generic collections in C#. Understand the basic lifecycle of an ASP.NET MVC request.

3. The React Ecosystem

If you choose the React path, master Hooks (useState, useEffect) and Component composition. Understanding how to fetch data from an API and manage state is critical.
