Entry-Level Engineering Role

.NET Developer

MHTECHIN - Building Innovative Software Solutions

Location: Pune, Maharashtra | Work Model: Hybrid

Drive Overview

At MHTECHIN, we build innovative and robust software solutions for clients across diverse industries. We are currently seeking enthusiastic .NET Developers who are passionate about coding, learning modern technologies, and contributing to real-world projects. This role is ideal for fresh graduates from the 2025, 2026, and 2027 batches looking to kickstart their careers in enterprise software development under the guidance of experienced senior developers.

Target Batches 2025, 2026, 2027
Experience Level 0 - 2 Years
Primary Stack C# / .NET Core

Your Role & Responsibilities

As a .NET Developer at MHTECHIN, you will be heavily involved in the end-to-end lifecycle of web and desktop application development using Microsoft's leading tech stack.

  • Software Development: Develop, test, and maintain applications using the .NET Framework and .NET Core architectures.
  • Code Quality: Write clean, efficient, and maintainable code strictly following modern industry best practices.
  • Cross-Functional Collaboration: Work closely with frontend developers, QA engineers, and project teams to deliver comprehensive, bug-free solutions.
  • Optimization & Debugging: Participate actively in code reviews, debugging sessions, and ongoing performance optimization.
  • Continuous Learning: Learn and implement new technologies and frameworks under the mentorship of senior staff.
  • Documentation: Maintain proper, high-quality documentation of code, APIs, and development processes.

Eligibility & Technical Requirements

C# Programming .NET Core / Framework ASP.NET MVC Web API SQL Server HTML / CSS / JS
  • Education: Bachelor’s degree in Computer Science, IT, or a related field.
  • Target Batches: Fresh graduates from batches 2025, 2026, and 2027 (or candidates with 0-2 years experience from recent batches).
  • Core Backend: Solid knowledge of C#, .NET Framework / .NET Core, and Object-Oriented Programming (OOPs).
  • Web Technologies: Familiarity with building robust web services using ASP.NET, MVC, and Web API.
  • Database: Good understanding of relational databases, specifically SQL Server.
  • Frontend: Understanding of frontend basics (HTML, CSS, JavaScript) is considered a strong plus.
  • Soft Skills: A problem-solving mindset, eagerness to learn, and strong communication and teamwork skills.

Expert Preparation Guide for MHTechin

1. Deep Dive into C# & OOPs

The foundation of this role is C#. Ensure you have absolute clarity on Object-Oriented principles: Inheritance, Polymorphism, Abstraction, and Encapsulation. Be ready to explain concepts like Abstract Classes vs. Interfaces, and memory management (Garbage Collection) in .NET.

2. .NET Core & Web API

MHTechin emphasizes modern frameworks. Understand the difference between .NET Framework and .NET Core. Practice building a simple CRUD application using ASP.NET Core Web API. Know how HTTP methods work (GET, POST, PUT, DELETE) and how to handle JSON payloads.

3. SQL Server & Database Logic

Backend developers must know how to interact with data. Brush up on writing complex SQL queries, understanding JOINs, Indexing, and Stored Procedures. Familiarize yourself with how Entity Framework (EF) Core acts as an ORM in .NET applications.

Why Join MHTechin?

MHTechin provides a highly collaborative and supportive work environment. As a fresh graduate, you will gain hands-on experience in real-world .NET projects. You won't be working in isolation; you will receive direct mentorship from experienced developers, gaining exposure to modern software development tools and frameworks, laying a strong foundation for your career growth.

Inclusive Hiring: MHTechin follows inclusive and unbiased hiring practices. Applications from all eligible candidates across India are encouraged for this Hybrid role in Pune.
