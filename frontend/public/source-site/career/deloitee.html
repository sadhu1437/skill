Deloitte Digital (USI)

Software Engineer I - VD

Front End User Experience Designer - Making an impact that matters.

Location: Available across 4 major locations in India (incl. Hyderabad)

Drive Overview

Deloitte Digital has created a new model for a new age: the creative digital consultancy. We combined the creative and digital capabilities of our studios and the broad reach of an advertising agency with the technical experience, deep business strategy, and relationships of one of the world's largest consultancies. We are seeking a Front End User Experience Designer / Software Engineer I to craft beautiful and scalable solutions. You will work with amazingly creative and engineering minds to build high-end GUIs, write APIs, and architect full-stack components.

Target Degree B.E/B.Tech/MCA/MSC/MS
Primary Domain Front End / UI / UX Dev
Core Stack React/Angular, ES6, Node

Your Role & Responsibilities

A wide range of challenges will ensure there’s never a dull moment. You will independently translate UX wireframes and mockups into pixel-perfect engineering code.

  • Frontend Architecture: Develop Rich GUI websites using Component-based architecture with frameworks like Angular, React, Vue, or Ember.
  • Full-Stack Awareness: Write robust APIs in server-side languages of your choice. Conceptual knowledge of Node.js and Express is critical.
  • TDD & Quality: Implement Test Driven Development by writing comprehensive unit and end-to-end test cases.
  • Database Integration: Demonstrate a solid understanding of both NoSQL (MongoDB) and Relational Databases.
  • Cloud & DevOps: Modify server configurations and actively engage with Cloud platforms such as AWS and Azure.
  • Design Thinking: Apply design thinking principles to explore tech possibilities and bridge the gap between design and scalable technical solutions.

Required Skills & Tech Stack

HTML5 / CSS3 JavaScript (ES6+) React / Angular / Vue Node.js / Express REST & AJAX AWS / Azure TDD / SonarQube
  • Core Front-End: HTML5, CSS3, JS, Responsive Web Development, and CSS3 Pre-Processors (LESS/SASS).
  • Modern JS: Mastery over Object-Oriented JS (OOJS), JavaScript Design Patterns, and Babel Transpilers.
  • Code Quality Tools: Experience with LINT tools, SonarQube, and Git Version Control.
  • Backend Basics: Knowledge of the complete HTTP request flow from browser to server and back.

How You'll Grow at Deloitte

Deloitte offers unparalleled professional development benefits. By joining, you gain access to:

  • DU: The Leadership Center: Access to the state-of-the-art learning center in Hyderabad, an extension of DU in Westlake, Texas.
  • Continuous Learning: Intensive trainings from external trainers, internal workshops, and premium subscriptions to platforms like Lynda.
  • Innovation & Travel: Participate in Hackathons, utilize the freedom to adopt new tech in live projects, and explore travel opportunities to global client locations.
  • Corporate Citizenship: Drive positive social impact through skill-based volunteerism and community initiatives.

Expert Preparation Guide for Deloitte Digital

1. Design Patterns & OOJS

Deloitte specifically looks for engineers who understand architectural patterns. Prepare to discuss MVC/MV* structures, Prototype chaining, Closures, and how you manage state across complex components in React or Angular.

2. Bridging Design and Code

You are applying for a "User Experience Designer" role with heavy engineering execution. You will likely be asked to review a wireframe and explain the exact HTML/CSS structure (Flexbox/Grid) and component hierarchy you would use to build it responsively.

3. The End-to-End HTTP Flow

The JD highlights "Knowledge of HTTP request flow." Be prepared to whiteboard what happens when a user clicks a button: from the AJAX/Fetch call in the UI, through the REST API endpoint (Node/Express), to the Database query (NoSQL/SQL), and back to the client render.

Recommended Extra Activities

  • Portfolio Review: Ensure your GitHub or personal portfolio has at least one full-stack project demonstrating a polished UI and a functioning backend API.
  • TDD Practice: Write basic unit tests for your UI components using Jest or Mocha to demonstrate your commitment to Code Quality (SonarQube/LINT awareness).
  • Deloitte Culture: Familiarize yourself with Deloitte's purpose: "To make an impact that matters." Bring this up during your HR interview.
