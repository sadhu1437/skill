Software Engineer - Full Stack

Sutherland - Unlocking Digital Performance. Delivering Measurable Results.

Location: Bengaluru, India | Full-Time

Drive Overview

Sutherland is a global digital transformation company leveraging Artificial Intelligence, Automation, and Cloud engineering. Working with iconic brands worldwide, we bring a unique value proposition through market-leading technology and business process excellence. We are currently expanding our team in Bengaluru with 3 open positions for Full-Stack Developers. In this role, you will combine human expertise with artificial intelligence to pioneer new solutions provided through a seamless “as a service” model.

Target Degree BE / BTech / MCA
Primary Stack React JS + Node.js
Target Domain Healthcare IT

Your Role & Responsibilities

This role demands a critical thinker who takes ownership of both the client-side user experience and the underlying backend architecture.

  • Frontend Architecture: Design, develop, and maintain responsive front-end components using React (Hooks, Context, Redux).
  • Backend Engineering: Build and maintain secure, scalable RESTful / GraphQL APIs using Node.js and Express.
  • Database Integration: Work heavily with relational databases like PostgreSQL to optimize application performance.
  • Quality Assurance: Write clean, reusable code, and perform unit/integration tests using Jest, Mocha, or Cypress.
  • Cloud & DevOps: Understand containerization technologies (Docker, Kubernetes) and deploy via CI/CD on cloud platforms (AWS/Azure/GCP).
  • Collaboration: Work closely with product managers and designers in an Agile/Scrum environment to drive technical decision-making.

Market Trend: Full-Stack Healthcare IT

The Healthcare IT sector is undergoing massive digital transformation to handle vast amounts of patient data securely and efficiently. By leveraging MERN/PERN Stacks (PostgreSQL, Express, React, Node) along with Microservices, companies like Sutherland are revolutionizing patient care and business operations. A Full-Stack Engineer capable of handling both modern UI components and containerized (Docker/K8s) backend services is among the most sought-after profiles in the Bengaluru tech ecosystem in 2026.

Sutherland Selection Process Roadmap

Candidates will undergo a rigorous evaluation to ensure a fit for both technical prowess and Sutherland’s digital chemistry:

1. Resume Screening

Shortlisting based on degree (BE/BTech CSE/IT, MCA) and relevant hands-on projects/experience in React & Node.js.

2. Coding Assessment

An online test evaluating algorithmic thinking, JavaScript/TypeScript proficiency, and database querying (PostgreSQL).

3. Technical Interview (Full Stack Deep Dive)

In-depth discussion covering React state management, Node.js backend architecture, REST/GraphQL differences, and microservices.

4. Managerial & HR Round

Evaluating your problem-solving skills, time-management, sense of ownership, and cultural fit within the fast-paced IT Services delivery domain.

Qualifications & Technical Skills

React (Hooks/Redux) Node.js / Express JavaScript & TypeScript PostgreSQL REST / GraphQL Docker / Kubernetes
  • Education: BE / BTech (CSE, IT), B.Sc. (Computers), BCA / MCA or Master’s in Computing / IT.
  • Frontend: Solid expertise in HTML5, CSS3, responsive design, and React functional components.
  • Backend: Hands-on experience with Node.js and backend frameworks.

Expert Preparation Guide for Sutherland

1. Master React State & Lifecycle

Sutherland explicitly emphasizes Hooks, Context, and Redux. Be prepared to explain how you avoid prop-drilling, manage global state, and optimize functional component re-rendering using useMemo and useCallback.

2. Backend Architecture (Node.js & Express)

Expect questions on how Node.js handles asynchronous operations (Event Loop). Practice designing a secure RESTful API or a GraphQL endpoint connected to a PostgreSQL database.

3. DevOps & Testing Awareness

Stand out by discussing your ability to write unit/integration tests using Jest, Mocha, or Cypress. Understanding how an application is containerized using Docker will give you a significant edge over other candidates.

Recommended Extra Activities

  • Cloud Deployment: Deploy your full-stack project using AWS (EC2/Amplify), Azure, or GCP to demonstrate real-world CI/CD capability.
  • Domain Research: Read up on basic Healthcare IT compliance (like HIPAA) to show domain awareness during the interview.
