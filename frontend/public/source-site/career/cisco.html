General Role & Responsibilities

You will develop software consistent with Cisco’s ‘Design Thinking Principles’—focusing on simplification, secure coding practices, and user privacy.

  • Software Development: Design, develop, troubleshoot, and debug software programs for enhancements and new products.
  • Infrastructure Tools: Develop tools supporting infrastructure platforms, including OS, compilers, routers, networks, and databases.
  • Agile Practices: Apply understanding of the SDLC and agile engineering practices (requirements analysis, unit testing, acceptance testing).
  • Security & Scale: Apply deep knowledge of secure coding principles. Execute tests for scale, reliability, and velocity within your own code.
  • Collaboration: Collaborate with team members to share learnings, review code, and address postmortems or incident reports.

Choose Your Engineering Track

Candidates can be aligned to one of the following specialized engineering tracks based on their skills and interview performance:

Networking Protocols

Focus on TCP/IP, routing, and switching. Requires basics of network debugging tools and security technologies (Firewall, IPS/IDS, VPN, IPsec, TLS). Strong Python scripting for optimization is key.

Application Software

Focus on object-oriented design and scaling applications to the cloud. Requires strong Python skills, open-source exposure, mobile app development basics, and an interest in UI/UX design.

Embedded & Systems Dev

Focus on kernel programming, user space, and system space. Requires very strong OS fundamentals, Python scripting, system-level debugging, and exposure to device drivers/BSPs.

Expert Preparation Guide for Cisco

1. Networking Foundation (CCNA Level)

Regardless of the track, Cisco expects a solid foundation in networking. You must understand the OSI model, TCP vs. UDP, IP addressing (Subnetting), and basic routing protocols. If applying for the Networking track, go deeper into Firewalls and VPNs.

2. Strong Python & Coding Skills

Python is heavily emphasized across all three tracks. Be prepared to write clean, optimized Python code. Understand memory management in Python, object-oriented concepts, and how to write unit tests for your code.

3. Operating Systems & Embedded Systems

If aiming for the Systems track, brush up on OS concepts: Deadlocks, Semaphores, Multithreading, Virtual Memory, and process scheduling. Knowledge of how a Linux kernel operates will give you a significant edge.
