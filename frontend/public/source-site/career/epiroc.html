Junior Full Stack Developer

Epiroc Mining India Ltd - Accelerating Sustainable Transformation

Location: Bengaluru (Hybrid) | Department: IT Engineering

Drive Overview

Epiroc is a leading productivity and sustainability partner for the mining and infrastructure industries. With customers in more than 150 countries, we develop innovative and safe equipment, digital solutions, and aftermarket support. We are currently hiring a Junior Full Stack Developer to join our dynamic IT hub in Bengaluru. In this role, you will be mentored by senior colleagues to build, support, and modernize enterprise applications and mobile backends that power global mining operations.

Experience Level 0 - 2 Years (Freshers)
Primary Stack C# / .NET / SQL
Work Mode Hybrid

Your Role & Responsibilities

This is a foundational role where you will grow by taking hands-on responsibility in building robust backend services and maintaining critical business applications.

  • Enterprise Development: Support the development, testing, and maintenance of enterprise applications guiding key business processes.
  • API & Backend: Assist in building scalable backend services, REST APIs, and integrations across web and mobile platforms.
  • Data Modeling: Work with business logic, data models, and cross-system data flows under the guidance of senior engineers.
  • Mobile Solutions: Contribute to mobile app support by ensuring secure and reliable communication between mobile clients and APIs.
  • DevOps & Releases: Contribute to deployments, monitoring, incident resolution, and day-to-day application support.
  • Continuous Modernization: Support the improvement and modernization of legacy solutions to maintain stable, cutting-edge operations.

Market Trend: Technology in Sustainable Mining

The global demand for metals and minerals required for green energy transitions (like EVs and wind turbines) is skyrocketing. Companies like Epiroc are leading the charge by integrating IoT (Internet of Things), Fleet Management, and Cloud Analytics into heavy machinery. By joining as a Junior Full Stack Developer, you are entering a niche, high-growth sector where your software directly impacts real-world industrial safety, equipment connectivity, and sustainable construction.

Required Skills & Qualifications

C# / .NET Core REST APIs SQL Databases Git / CI-CD Angular / React (Plus) Azure (Plus)
  • Programming Foundation: Good foundation in C#, .NET / .NET Core, or other modern object-oriented languages.
  • Web Technologies: Basic understanding of web development, REST-based integrations, and API architecture.
  • Databases: Basic knowledge of SQL and relational database management.
  • Experience: Relevant internships, academic projects, or early professional experience in software development are highly valued.
  • Soft Skills: Curious, eager to learn, structured, quality-focused, and capable of clear communication within an Agile team.
  • Nice-to-Have: Exposure to modern frontend frameworks (Angular/React) and cloud/DevOps tools (Azure DevOps).

Expert Preparation Guide for Epiroc

1. Mastery of C# & .NET Core

Epiroc builds enterprise-grade backend systems. Master Object-Oriented principles, LINQ, Entity Framework, and asynchronous programming (async/await) in C#. Be ready to explain how you structure a basic .NET Web API.

2. REST API & Integration Logic

Understand how systems talk to each other. Brush up on HTTP methods (GET, POST, PUT), status codes, and JSON data handling. They specifically mention mobile-to-API communication, so knowing how to secure an endpoint (e.g., JWT tokens) is a huge plus.

3. SQL Fundamentals

Data is central to fleet management and service operations. Practice your SQL Joins, indexing basics, and database normalization to demonstrate you can handle enterprise data flows.

Recommended Extra Activities

  • Build a Connected App: Create a simple .NET Core API that serves data to an Angular or React frontend (e.g., a mock "Equipment Tracker"). Host the code on GitHub.
  • Learn Azure DevOps Basics: Familiarize yourself with CI/CD pipelines. A basic understanding of how code is pushed from a repo to a server using Azure will make you stand out.
  • Epiroc Industry Research: Read up on Epiroc’s digital solutions like "Certiq" (telematics system). Mentioning equipment connectivity in your interview shows genuine interest.
