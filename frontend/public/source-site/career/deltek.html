Associate Software Engineer

Deltek - The Recognized Global Standard for Project-Based Businesses

Location: Bangalore, India | Professional Services Team

Drive Overview

Deltek is globally recognized for creating a balanced, values-driven environment where every employee is empowered to do their best work. Named a Best Place to Work in Asia by World HRD Congress, Deltek’s Professional Services group assists global clients in integrating and automating their project lifecycles. We are seeking early-career Associate Software Engineers in Bangalore to design, develop, and deploy custom technical solutions using modern engineering and AI-first methodologies.

Experience Level 0 - 1 Year (Entry Level)
Primary Stack Python / Node.js / Java
Job ID 10948BR

Your Role & Responsibilities

This role heavily emphasizes learning and an AI-first methodology. You will use AI-powered tools (like Copilots) to design, develop, and maintain scalable solutions.

  • Custom Development: Develop and support client-specific customizations, API integrations, and automation under expert guidance.
  • Code Ownership: Deliver assigned development tasks with high quality, adhering strictly to estimated effort and timelines.
  • DevOps & SDLC: Follow established tools, coding standards, CI/CD pipelines, and enterprise security practices.
  • Global Collaboration: Partner effectively across a global ecosystem, including Senior Developers, Project Managers, and Cloud Operations.
  • Quality Assurance: Fix defects, support testing activities, and perform code rework to maintain high customer satisfaction.
  • Continuous Learning: Actively engage in learning new Deltek products and integrating prompt engineering into your daily workflow.

Success Criteria for the Role

Deltek evaluates its engineers based on clear, outcome-driven metrics. To thrive in this role, you must demonstrate:

  • Requirement Clarity: Quickly grasp technical specifications to minimize the need for rework.
  • Execution: Proactively communicate risks or blockers to avoid scope drift while meeting deadlines.
  • Quality: Deliver code with low defect rates, leading to successful QA/UAT outcomes.
  • AI Adoption: Demonstrate massive efficiency gains by utilizing AI to write specifications, improve code quality, and automate testing.

Required Skills & Qualifications

Python / JavaScript Node.js / Java C / C++ REST APIs Git / CI/CD AI / LLM Tools
  • Academics: Bachelor’s degree (or final‑year student) in Computer Science, Engineering, or a related technical discipline.
  • Experience: Entry‑level experience through academic projects, internships, labs, or open‑source contributions.
  • Programming: Basic proficiency in at least one language (Node.js preferred, Python, Java, or C/C++).
  • CS Foundations: Strong knowledge of Data Structures, Algorithms, and Object-Oriented Programming (OOP).
  • AI Advantage: Hands‑on experience or foundational knowledge of AI/LLM‑based tools (like GitHub Copilot) and prompt engineering is a major plus.

Expert Preparation Guide for Deltek

1. Programming & API Mastery

Since Deltek focuses heavily on integrating enterprise solutions, practice building basic REST APIs using Node.js (Express) or Python (FastAPI/Django). Be prepared to explain how APIs interact with a database.

2. AI-First Development Mindset

Deltek specifically requests candidates who use AI tools for efficiency. During your interview, be ready to explain how you have used ChatGPT or GitHub Copilot to debug an error, write a unit test, or generate boilerplate code.

3. Data Structures & Logic

Brush up on your core CS fundamentals. You should be able to clearly explain the time and space complexity of common data structures like HashMaps, Arrays, and Trees.

Recommended Extra Activities

  • Open Source & GitHub: Push a recent academic or personal project to GitHub. Ensure the code is clean and accompanied by a well-written README file.
  • Mock Integration: Build a small script that fetches data from a public API, parses the JSON, and logs specific metrics. This showcases your integration capabilities.
  • Company Research: Visit www.deltek.com to understand what "ERP (Enterprise Resource Planning)" means and how project-based businesses operate.
