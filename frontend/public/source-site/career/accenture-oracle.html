Custom Software Engineer

Accenture - Let there be change

Packaged Application Development Associate | Job No. ATCI-5510520-S2034656

Drive Overview

Accenture is a leading global professional services company that helps the world's leading businesses, governments, and other organizations build their digital core and optimize their operations. We are currently seeking a Custom Software Engineer for our Hyderabad office to join our team. In this role, you will be heavily involved in Oracle Cloud Infrastructure (OCI) Administration, working collaboratively to deploy, monitor, and maintain scalable cloud environments.

Experience Level 0 - 2 Years
Mandatory Skill Oracle Cloud (OCI) Admin
Job Location Hyderabad, Telangana

What You Will Do

As a Custom Software Engineer, a typical day involves creating tailored software solutions by designing, coding, and improving various components within systems or applications.

  • Infrastructure Management: Manage and administrate resources efficiently within the Oracle Cloud Infrastructure (OCI).
  • Problem Solving: Participate actively in problem-solving discussions to resolve cloud configuration and operational issues.
  • Agile Collaboration: Collaborate with team members to understand project requirements and contribute to robust solution designs.
  • Testing & Debugging: Assist in testing, monitoring, and troubleshooting cloud infrastructure and software components to maintain optimal system performance.
  • Documentation: Document development processes, network configurations, and maintain clear communication within the team.
  • Deployment Support: Support the deployment and maintenance of software solutions in production environments.

Professional & Technical Skills

Oracle Cloud (OCI) Cloud Administration Scripting & Automation Networking Concepts IAM / Security
  • Must-Have Skills: Strong proficiency in Oracle Cloud Infrastructure Administration.
  • Automation: Familiarity with scripting languages (like Python or Bash) to automate routine tasks and improve operational efficiency.
  • Cloud Tools: Experience with cloud resource management and automation tools related to Oracle Cloud Infrastructure (e.g., Terraform, Ansible).
  • Security & Network: Deep understanding of network configurations (VCNs, Subnets), security principles, and Identity & Access Management (IAM) within cloud environments.
  • Education Requirement: A standard 15 years full-time education (e.g., B.E/B.Tech, BSc + MCA trajectory) is strictly required.

Accenture Preparation Strategy for OCI Role

1. Oracle Cloud Infrastructure (OCI) Fundamentals

As OCI Administration is the mandatory skill, you must have a clear understanding of its core components. Brush up on Compartments, Virtual Cloud Networks (VCN), Security Lists, Route Tables, and Identity and Access Management (IAM) in Oracle Cloud. Be ready to explain how you would isolate resources for different teams.

2. Infrastructure as Code (IaC) & Scripting

The JD specifically highlights familiarity with scripting languages to automate routine tasks. Practice answering how you would use Terraform (OCI Resource Manager), Python (OCI Python SDK), or OCI CLI to automate the provisioning of a compute instance or object storage bucket.

3. Cloud Security and Networking

Expect scenario-based questions during the technical interview. For instance, "How would you troubleshoot a connection issue between an on-premise network and an OCI VCN using FastConnect or an IPSec VPN?" Ensure your concepts on cloud security principles are solid.
