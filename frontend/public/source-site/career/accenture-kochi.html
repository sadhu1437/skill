Associate Engineer - Backend Development

Accenture (ACS Song) - Packaged Application Development Associate

Level 12 (Associate) | Location: Kochi | Job No: R00327042

Role Overview

Accenture is seeking a skilled and motivated Java/Spring Developer to join the ACS Song team as an Associate Engineer in Kochi. In this Level 12 position, you will utilize your 0–2 years of hands-on experience to design, develop, and maintain high-performance backend applications. The ideal candidate will have a strong foundation in object-oriented programming and modern software engineering best practices to build scalable APIs and eCommerce features.

Experience Level 1 - 2 Years
Must Have Skills Java / Spring Boot
Job Location Kochi, Kerala

Key Responsibilities

You will be responsible for writing clean, scalable code, collaborating with cross-functional teams, and contributing to all phases of the software development lifecycle.

  • Code Development: Write clean, maintainable, and well-documented Java code following team coding standards with good debugging skills.
  • Collaboration: Work on technical implementation, assist other developers, and consult in the development process.
  • Delivery & Quality: Show exceptional productivity and attention to product quality issues. Be accountable for delivering tasks to agreed standards.
  • Architecture: Adhere to development standards and architectural guidelines set by the Solution Design team.
  • Feature Integration: Contribute to the development of eCommerce features and support integration with external systems under guidance.
  • Troubleshooting: Act as the key trouble-shooter in complex or escalated incidents and provide innovative ideas in an ever-changing environment.
  • Continuous Learning: Effectively assimilate new skills, use new technologies, and keep up with trends relevant to the project and team.

Professional & Technical Skills Required

Java 11+ Spring Boot RESTful APIs Data Structures & Algorithms Junit & Mockito SQL / NoSQL CI/CD & SonarQube
  • Core Java: Strong development skills in Java 11 or above. Solid understanding of OOPS concepts and design principles (SOLID and DRY).
  • Frameworks: Hands-on experience with Spring and developing/maintaining backend services and RESTful APIs using Spring Boot.
  • Problem Solving: Strong acumen in Data Structures, Algorithms, problem-solving, and Logical/Analytical skills.
  • Java Fundamentals: Good knowledge of Enums, Collections, Annotations, Generics, Autoboxing. Sound understanding of Exception handling, Serialization/Deserialization, and Immutability.
  • Advanced Concepts: Basic understanding of multi-threading (Java's Concurrent package) and Java Memory Management (JMM), including garbage collection.
  • Database & Web Services: Experience in RDBMS or NoSQL databases, writing SQL queries, and hands-on experience creating and consuming RESTful webservices.
  • Testing & Tooling: Experience writing Junit test cases using Mockito/Power Mock. Hands-on with logging frameworks (SLF4J/LogBack/Log4j), code quality tools like SonarQube, and code management tools.
  • Bonus Skills: Familiarity with CI/CD pipelines, cloud technologies, in-memory caching concepts, and Agile Project Management.

Expert Preparation Guide for Accenture Backend

1. Deep Dive into Java 11+ Features

The JD specifically asks for Java 11 or above. Ensure you are familiar with modern Java features such as the Local-Variable Type Inference (var), new String and File methods, and enhancements to the Streams API. You must also be able to explain Java Memory Management (JMM) and how the Garbage Collector functions.

2. Master Spring Boot & REST APIs

Be prepared to build or explain a basic RESTful API using Spring Boot. You should understand annotations like @RestController, @RequestMapping, @Autowired, and how Dependency Injection works in the Spring framework. Knowing how to handle exceptions globally in Spring is a big plus.

3. SOLID Principles & Unit Testing

Accenture emphasizes clean, maintainable code. Be ready to explain the SOLID design principles with examples. Furthermore, practice writing unit tests using JUnit and Mockito. Knowing how to mock external dependencies effectively shows that you write robust, production-ready code.

4. Data Structures & Algorithms

Expect a technical assessment or whiteboard round focusing on core DSA. Brush up on your problem-solving skills, focusing particularly on Collections (Lists, Maps, Sets), time/space complexity, and string/array manipulation algorithms.
