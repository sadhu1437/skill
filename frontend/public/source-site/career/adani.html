Adani Digital Technology Role

Graduate Engineer Trainee - Technology

Adani Group - Growth with Goodness

Location: Ahmedabad, Gujarat, India | Fresher Hiring

Drive Overview

The Adani Group is one of India's largest and most diversified conglomerates, with market leadership in transport logistics and energy utility portfolios. We are scaling our digital and technology platforms and are looking for bright Graduate Engineer Trainees (GETs) to join our engineering hub in Ahmedabad. In this role, you will be heavily involved in API Development, Backend Architecture, and Business Logic Implementation using scalable modern technologies. This is a unique opportunity to build robust systems that power critical infrastructures across the nation.

Target Audience Freshers (0 Yrs)
Required Degree B.E / B.Tech (CS/IT)
Primary Stack C# / .NET / Node.js

Your Role & Responsibilities

As a GET in the Technology team, you will be the backbone of scalable applications, developing high-performance APIs and optimizing data layers for massive user bases.

  • API Development: Design, develop, and maintain backend APIs, including Customer JSON APIs and Dotrez APIs (aviation tech).
  • Business Logic Implementation: Build core business logic using APIs, ensuring high performance and alignment with system requirements.
  • Scalable Architecture: Utilize technologies like C#.Net, Node.js, MVC, SQL, and No-SQL to design web services.
  • Optimization: Build and optimize API caching layers for mobile apps and websites to significantly reduce latency.
  • Code Quality: Participate in rigorous design and code reviews with developers, and test-case reviews with QA teams.
  • Testing: Perform thorough unit and module testing to resolve errors before production deployment.
  • Digital Mindset: Keep up with digital and AI advancements to enhance internal business capabilities.

Market Trend: Enterprise APIs & Tech Convergence

With companies expanding their digital footprints across aviation, ports, and energy, robust API development is essential. Adani’s use of Dotrez APIs points to high-scale operations like airport and travel management. Building a common API layer using GraphQL, REST, C#.NET, and Node.js offers you a high-value skill set. Mastering these backend frameworks makes you an incredibly valuable asset in the global Software Development market in 2026.

Required Skills & Qualifications

C# .NET / Node.js REST APIs / GraphQL SQL & No-SQL OOP Fundamentals Caching & Optimization JQuery / AJAX
  • Education: B.E / B.Tech in Computer Science/Engineering or IT.
  • Experience: Fresher.
  • Core Tech: Strong understanding of Object-Oriented Programming (OOP) fundamentals.
  • Frameworks: Proven knowledge of Node.js or .NET, MVC patterns, JQuery, GraphQL, REST APIs, and AJAX frameworks.
  • Databases: Familiarity with both relational (SQL) and non-relational (No-SQL) databases.
  • Soft Skills: Strong collaboration skills to work with Lead API Engineers and external vendors.

Expert Preparation Guide for Adani Technology

1. REST APIs vs GraphQL

The job description mentions both REST and GraphQL. Be prepared to explain the architectural differences between the two. When would you use GraphQL (to prevent over-fetching) versus a standard REST endpoint?

2. Caching Strategies

A specific responsibility is "optimizing API caching layers." Brush up on caching mechanisms like Redis or Memcached. Understand how caching reduces latency in mobile applications.

3. Strong OOP & Database Knowledge

Expect questions on OOP concepts (Inheritance, Polymorphism) implemented in C# or JavaScript (Node.js). Also, be ready to write SQL queries and explain when you would choose a No-SQL database (like MongoDB) over a SQL database.

Recommended Extra Activities

  • Build a Node.js / .NET API: Create a functional API that interacts with a No-SQL database and pushes the code to GitHub. Implement basic Redis caching to show you meet the exact job requirements.
  • Review API Documentation: Familiarize yourself with writing API docs using tools like Swagger / OpenAPI. Adani requires comprehensive documentation skills.
  • Understand Dotrez: Dotrez is a major airline/travel reservation platform. Reading briefly about aviation IT systems will give you a strategic edge during interviews.
