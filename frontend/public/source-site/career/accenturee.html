Data Eng, Mgmt & Governance | Job No: ATCI-5501723-S2010427

Drive Overview

Accenture is a leading global professional services company that helps the world's leading businesses, governments, and other organizations build their digital core and optimize their operations. We are currently seeking a Custom Software Engineer for our Pune office to join the Data Eng, Mgmt & Governance team. In this role, you will be leveraging Python to design, code, and enhance software components across various enterprise systems and applications.

Experience Level 0 - 2 Years
Mandatory Skill Python Programming
Job Location Pune, Maharashtra

What You Will Do

As a Custom Software Engineer, your typical day involves creating tailored software solutions by designing, coding, and improving various components within systems using modern Agile practices.

  • Software Customization: Develop custom software solutions to design, code, and enhance components across systems or applications.
  • Modern Methodologies: Use modern frameworks and agile practices to deliver scalable, high-performing solutions tailored to specific business needs.
  • Problem Solving: Participate actively in problem-solving discussions to resolve software issues and optimize performance.
  • Documentation: Assist in documenting software design and development processes to facilitate team understanding and future maintenance.
  • Collaboration & QA: Collaborate with cross-functional teams to gather requirements and contribute to code reviews and testing activities to ensure software reliability.

Market Trend: Python in Data Engineering

Python has become the undisputed language of choice for Data Engineering, Management, and Governance. With the exponential growth in data analytics and AI integration, organizations are heavily relying on Python to build scalable ETL pipelines, automate data workflows, and develop robust backend systems. Joining Accenture's Data Eng team with a Python focus places you at the forefront of one of the highest-paying and most secure technology tracks in 2026.

Technical Skills & Eligibility

Python Object-Oriented Programming (OOP) Git / Version Control Debugging Agile Practices
  • Must To Have Skills: Strong proficiency in Python (Programming Language).
  • Programming Concepts: Strong understanding of Object-Oriented Programming (OOP) concepts and core software development principles.
  • Development Tools: Hands-on experience with version control systems (like Git) to manage codebases effectively.
  • Code Quality: Ability to write clean, maintainable, and efficient code following industry best practices.
  • Troubleshooting: Familiarity with debugging and troubleshooting techniques to resolve complex software issues.
  • Education: Minimum 15 years of full-time education (e.g., standard B.E/B.Tech, BSc, BCA + MCA trajectory) is mandatory.

Accenture Preparation Strategy

1. Python Fundamentals & Data Structures

Since Python is the mandatory skill for this role, expect deep-dive questions on Python's core data structures (Lists, Dictionaries, Sets, Tuples), decorators, generators, and list comprehensions. Be ready to write pseudo-code or solve basic algorithms using Python.

2. Object-Oriented Programming (OOP) in Python

The job description explicitly mentions OOP concepts. You must know how to implement Classes, Objects, Inheritance (including multiple inheritance in Python), Polymorphism, and Encapsulation using Python syntax (e.g., the use of __init__ and self).

3. The Accenture Selection Process

Accenture's hiring process for 0-2 year experienced candidates usually involves:

Cognitive & Technical Assessment: Tests English ability, critical reasoning, and technical fundamentals (pseudo-coding, networking, cloud).
Coding Assessment: A timed coding test where you will need to solve 2 problems. Ensure you select Python and focus on edge cases.
Communication Assessment: An AI-based spoken English test evaluating sentence mastery, vocabulary, and pronunciation. Take this in a quiet room!
Technical & HR Interview: A combined round focusing on your Python knowledge, final year/previous company projects, and cultural fit.
