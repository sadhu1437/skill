QA Automation Engineer

Virtusa - Accelerating Business Outcomes Through Digital Engineering

Location: PCS HYD, Hyderabad, Telangana | Experience: 0-2 Years

Drive Overview

Virtusa is a global provider of digital business strategy, digital engineering, and information technology (IT) services. We help clients change, disrupt, and unlock new value. We are seeking a motivated and detail-oriented QA Automation Engineer (Software Engineer) with a strong foundation in performance testing to join our dynamic team in Hyderabad. This role is perfect for recent graduates or early-career professionals looking to grow their automation skills while ensuring the quality and performance of world-class software products.

Target Experience 0 - 2 Years (Freshers)
Primary Domain Automation & QA
Target Degree CS / IT Graduates

Your Role & Responsibilities

In this role, you will go beyond manual testing. You will design automated frameworks and act as the gatekeeper for software performance before it reaches end-users.

  • Automated Testing: Design, develop, and execute automated test scripts specifically tailored for performance testing.
  • Performance Analysis: Analyze performance test results and provide actionable, data-driven insights to the development team.
  • Collaboration: Work closely with cross-functional teams to understand product requirements and ensure strict quality standards are met.
  • Strategy: Participate actively in test planning and strategy discussions during Agile sprints.
  • Process Improvement: Continuously improve testing processes and methodologies to accelerate release cycles.
  • Documentation: Document test cases, execution results, and software defects in a clear, concise, and reproducible manner.

Market Trend: Test Automation & CI/CD

As modern software systems scale rapidly into the cloud, companies can no longer afford slow manual testing cycles. Quality Assurance (QA) has evolved into Quality Engineering (QE). This role at Virtusa places you at the heart of this shift. By mastering automation frameworks and integrating performance tests into CI/CD pipelines, you ensure applications do not break under heavy user loads. Expertise in performance tools like JMeter and backend languages (Java/Python) is currently one of the most stable and high-in-demand skill sets in the IT industry.

Eligibility & Technical Requirements

Java / Python / C# Performance Testing JMeter / LoadRunner CI / CD Pipelines Git Agile / SDLC

  • Experience: 0 to 2 years of experience. Highly motivated freshers are encouraged to apply.

  • Strong analytical, problem-solving, communication, and teamwork abilities.

Expert Preparation Guide for Virtusa QA

1. Programming Fundamentals (Java/Python)

Automation testing requires solid coding skills. You must be comfortable with Object-Oriented Programming (OOPs) concepts like Inheritance, Polymorphism, and Exception Handling. Be prepared to write simple programs to reverse a string, find duplicates, or manipulate arrays.

2. Performance Testing Tools

The JD explicitly highlights JMeter and LoadRunner. You should know the difference between Load Testing, Stress Testing, and Spike Testing. Understand how to simulate 1,000 concurrent users hitting an API endpoint using JMeter.

3. Version Control & CI/CD

Understand the Git workflow (Clone, Branch, Commit, Push, Merge). Know the basic concept of CI/CD—how a tool like Jenkins or GitLab Actions automatically triggers test scripts whenever a developer pushes new code.

Recommended Extra Activities

  • Build a Selenium/Cypress Script: Write an automated script that logs into a demo website and asserts the page title. Push this code to GitHub.
  • JMeter Practice: Download Apache JMeter and run a simple load test against a public placeholder API (like JSONPlaceholder). Take a screenshot of the aggregate report.
  • Agile Research: Review the ceremonies of Scrum (Sprint Planning, Daily Standup, Retrospective). You will be asked how QA fits into these agile cycles.
