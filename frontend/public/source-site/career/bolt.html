100% Remote / WFH Role

Software Engineer

Bolt - Setting a New Standard for E-commerce Checkout

Location: India (Remote) | Function: Backend / Full Stack Development

Drive Overview

Founded in 2014, Bolt is revolutionizing the e-commerce landscape with its composable checkout solutions, utilized by enterprise merchants like Revolve and Casper. We aim to achieve the highest conversion rates with zero passwords and seamless shopper recognition across tens of millions of accounts. We are hiring a Software Engineer to join our remote team. In this role, you will build Bolt's leading checkout and payments products, tackling compliance, scaling systems, and writing robust code in Golang and React.

Target Batch 2026 or Recent Grads
Experience Level 0 - 3 Years
Primary Stack React, Golang, Node.js

Your Role & Responsibilities

You will ramp up quickly on Bolt's platform, taking ownership of real feature development from open PRs to production deployment.

  • Full Stack Development: Ship features end-to-end using React in the frontend and Golang in the backend. Add and maintain REST/GraphQL endpoints for shopper/merchant screens.
  • AI Integration: Utilize LLMs to build features within a well-defined scope to accelerate development.
  • Data Management: Design schemas and write queries in PostgreSQL, ensuring data consistency across microservices.
  • Fintech Compliance: Ship code aligned with PCI DSS, AML, and KYC standards, contributing to fraud prevention and tokenization features.
  • Observability: Leverage Datadog for service health monitoring, logging, and alerting across payment systems.

Market Trend: Composable Commerce & Fintech

The e-commerce checkout experience is no longer just a form; it is a highly secure, conversion-optimized data pipeline. "Composable commerce" allows businesses to plug-and-play checkout modules without overhauling their entire website. By joining Bolt, you are working at the intersection of Fintech (Payments/Fraud) and High-Scale E-commerce. Mastering Golang for concurrent backend processing and strict PCI compliance makes this a highly lucrative career path in the global remote tech market.

Eligibility & Technical Requirements

Golang / Node.js React.js PostgreSQL REST / GraphQL Git Fluency

Required Skills:

  • Education/Batch: Graduating in 2026 or graduated within the past 12 months.
  • Portfolio Requirement: Must have at least one full-stack project you can demo (Frontend, Backend, and Database deployed and accessible).
  • Frontend: Working knowledge of React or a similar component framework.
  • Backend: Proficiency in at least one backend language (Go, Node.js, Python, Java) with a genuine interest in writing in Go (Golang).
  • Database: Comfortable with SQL and relational database concepts.
  • Collaboration: Git fluency and the ability to do clear written communication in an async, remote team environment.

Nice to Have (Bonus Skills):

  • Exposure to Kubernetes, AWS, or GCP cloud environments.
  • Curiosity or knowledge about fintech compliance (PCI, PSD2, SOC 2).
  • Familiarity with event-driven architectures (Kafka, RabbitMQ).
  • Open-source contributions or a technical blog.

Expert Preparation Guide for Bolt

1. Prepare Your Demo Project

The JD explicitly requires a deployed full-stack project. Ensure your project is live (e.g., frontend on Vercel/Netlify, backend on Render/Heroku, database on Supabase/ElephantSQL). Be ready to open your code and explain your architectural decisions, database schema, and how you handle API routing.

2. Understand Golang & Concurrency

If you don't know Go yet, learn the basics of how it handles concurrency (Goroutines and Channels) compared to Node.js or Python. Expressing a strong willingness and foundational understanding of why Go is used for high-performance backends will impress the team.

3. Read Code You Didn't Write

Bolt values "Git fluency and ability to read and extend a codebase you didn't write." Practice reviewing open-source projects on GitHub, understanding their structure, and figuring out where to add a new feature.
