Associate Software Engineer - UI

Ontic - AI-Powered Connected Intelligence Platform

Location: Pune, India | Work Model: On-site

Drive Overview

Ontic provides software that helps corporate and government security teams identify threats, assess risk, and respond faster to keep people and organizations safe. Fortune 500 companies and federal agencies rely on Ontic to support security programs such as executive protection, threat intelligence, and corporate investigations. We are hiring an Associate Software Engineer (Frontend) in Pune to contribute to the development of highly interactive user interfaces for our robust SaaS platform.

Experience Level 0 - 2 Years
Primary Stack React, TypeScript, JS
Department Engineering - Frontend

Your Role & Responsibilities

This is an early-career role designed for engineers building strong foundations in frontend development. You will grow into an independent contributor while writing high-quality code.

  • Frontend Development: Contribute to building user interfaces and features using JavaScript, TypeScript, React, HTML, and CSS.
  • API Integration: Work with APIs to integrate complex frontend views with robust backend services.
  • Code Quality: Write clean, maintainable, and reusable code following established engineering and security standards.
  • Design & Accessibility: Follow best practices in component design, application state management, and web accessibility (a11y).
  • Debugging: Support basic debugging and issue resolution in both development and production environments.
  • Collaboration: Communicate progress and blockers clearly with engineers, designers, and product teams.

Market Trend: Tech in Corporate Security

The corporate security and threat intelligence market is experiencing massive growth, driven by AI and data analytics. Building UI for platforms like Ontic means developing dashboards that visualize complex threat matrices and real-time alerts. Speed, performance, and flawless rendering are critical here. Mastery of TypeScript and React in this context provides a highly specialized and lucrative career path in the global SaaS landscape.

Required Skills & Experience

JavaScript & TypeScript React.js HTML5 / CSS3 REST APIs (Async/Await) Git / Version Control Frontend Build Tools
  • Experience: 0–2 years of software engineering experience. Internships, academic, or personal projects count heavily!
  • Core Tech: Foundational knowledge of modern JavaScript (ES6+), HTML, and CSS.
  • Frameworks: Basic to intermediate understanding of React (or similar component-based frontend frameworks).
  • Asynchronous Logic: Familiarity with REST APIs, promises, and async/await paradigms.
  • Mindset: Strong willingness to learn, adapt, and grow in a fast-paced environment.

Expert Preparation Guide for Ontic

1. Master React State & Lifecycle

Ontic expects you to build scalable UI components. Be prepared to explain how you manage state using Hooks (useState, useEffect, useContext) and how you prevent unnecessary re-renders in complex dashboards.

2. TypeScript vs. JavaScript

Since TypeScript is a core requirement, understand its advantages in a large codebase. Be ready to discuss Types vs. Interfaces, strict typing, and how TS helps catch bugs at compile time.

3. API Handling & Promises

Practice writing clean async/await functions to fetch data from an API. Know how to handle loading states, error boundaries, and network timeouts gracefully.
