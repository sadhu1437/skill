Associate Software Engineer - Systems

Nasuni - The Foundation for Enterprise AI and Unstructured Data

Location: Hyderabad (Hybrid) | 3 Days Office / 2 Days Remote

Role Overview: Platform Engineering

Nasuni is hiring an Associate Software Engineer – Systems (Platform) to join the Platform Engineering team in Hyderabad. Unlike standard application development, this role is for engineers who enjoy working close to the metal. You will focus on building and improving the Linux-based foundation of Nasuni’s NAS appliance platform using Python and C++. This platform runs across physical, virtual, and cloud environments, managing massive volumes of file data for global organizations.

Target Level Entry Level (0-2 Yrs)
Primary Stack Linux, Python, C++
Work Model Hybrid (Hyderabad)

Responsibilities & Scope

This is a foundational role where you will grow from executing scoped tasks to contributing meaningfully to large-scale infrastructure systems.

  • Systems Development: Develop Linux-based software using C++ and Python.
  • Automation: Write scripts and tooling (Bash/Python) for system workflows and automation.
  • Platform Reliability: Debug real-world issues across the Linux OS, filesystem (ext4, XFS), and networking layers.
  • Testing: Write and maintain automated tests using frameworks like pytest.
  • Modern Tooling: Use AI-assisted code assistants and log analysis tools to improve debugging productivity.
  • Collaboration: Participate in code reviews and engineering discussions with global senior mentors.

Market Trend: The Rise of Unstructured Data

As enterprises adopt AI, the management of unstructured data (files, images, videos) has become the new frontier. Nasuni, backed by Vista Equity Partners, is at the intersection of cloud storage and AI. Joining this team gives you experience in building the unstructured data foundation that powers the AI models of tomorrow.

Qualifications & Skill Set

Operating Systems Data Structures Linux Internals Python / C++ Shell Scripting Virtualization
  • Education: B.Tech / BE in Computer Science or a related field (2024, 2025, or 2026 Batch).
  • Experience: 0–2 years (including internships or non-trivial systems projects).
  • Fundamentals: Solid understanding of Operating Systems and Algorithms.
  • Hands-on: Critical requirement for project experience in Linux environments.
  • Preferred: Familiarity with Linux internals (memory, processes), ext4/XFS filesystems, and Git workflows.

Expert Preparation Roadmap for Nasuni

1. Linux Systems Programming

Nasuni interviews focus heavily on Operating Systems. Master the concepts of Process Management, Threading, Memory Allocation (Heap vs Stack), and how a Kernel interacts with Hardware.

2. Python for Systems

Practice using Python for more than just scripts. Understand how Python manages memory and how to use it for high-performance log analysis and system tool development.

3. Debugging Skills

Be ready to explain how you would debug a "System Slowdown" or a "Network Timeout." Knowing tools like top, strace, gdb, or tcpdump will set you apart.

Recommended Extra Activities

  • Open Source Contribution: Try fixing a bug or improving documentation in a Linux-based open-source project (e.g., a specific storage tool or driver).
  • Build a "Mini-OS": Create a simple task scheduler or a basic filesystem manager in C++ as a personal project to demonstrate "non-trivial" system building.
  • AI for Systems: Experiment with using LLMs (like ChatGPT or Copilot) to analyze complex Linux logs. Nasuni specifically mentions AI-assisted debugging in the JD.
