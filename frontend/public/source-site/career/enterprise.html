Drive Overview

Innovation is at the heart of everything we do at American Express. Your Role & Impact

You won't be on the sidelines. As an Apprentice, you will function as a core member of an agile team and make an impact right away across mobile, web, and backend services.

  • Software Development: Write scalable, high-performance code with one or more programming languages including Java, JavaScript, .NET, or Python.
  • Agile Execution: Work on API specifications, conduct code reviews, and execute testing in ongoing sprints.
  • Omnichannel Design: Design and develop new customer-facing applications on multiple channels like native iOS, Android, web, and social integrations.
  • Innovation: Build proof of concepts (POCs) and automation tools to continuously improve technical workflows.
  • Data Systems: Design and implement web-enabled systems tailored for secure and efficient data collection.

Expert Preparation Guide for American Express

1. Programming Fundamentals

The JD specifically lists Java, JavaScript, .NET, and Python. Be prepared to dive deep into one of these. Understand Object-Oriented Programming (OOP), memory management, and core data structures. Live coding or technical assessments will focus on logic optimization.

2. API Specifications & Agile

Since you will be working on "API specs" in an "agile team," make sure you know what a RESTful API is, how JSON payloads work, and the basic principles of Scrum (Sprints, Stand-ups, Retrospectives).

3. The "Amex Culture" Fit

American Express is built on a 175-year history of shared values: Trust, Security, and Service. Be ready to answer behavioral questions using the STAR method (Situation, Task, Action, Result) demonstrating your "never-settle" attitude and customer obsession.
