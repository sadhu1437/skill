Java L1 Support Engineer

Lenskart - Transforming Vision Through Technology

Locations: Bangalore / Manesar / Bhiwadi Plant

⚠️ Night Shift Role: Operating Hours are strictly from 9:00 PM to 6:00 AM

Drive Overview

Lenskart is India's fastest-growing eyewear business, seamlessly blending fashion and technology. We are looking for a dedicated Java L1 Support Engineer to join our Technology team. In this highly critical role, you will bridge the gap between our physical manufacturing/warehouse operations and our core development team. You will be the frontline technical problem solver, ensuring that our plant operations run smoothly without technical interruptions during the night shift.

Target Experience Fresher / 0-1 Year
Primary Stack Java & MySQL
Shift Timing 9:00 PM to 6:00 AM

Your Role & Impact

This role uniquely blends technical troubleshooting with active ground-level communication. You will be resolving tech production issues directly in the plant environment.

  • Plant Support: Actively monitor and resolve technical production issues within the manufacturing and warehouse plant.
  • Communication Hub: Communicate daily with Warehouse supervisors and operations staff to understand the functional issues they face.
  • Technical Translation: Translate complex operational problems into technical requirements to explain them clearly to the Core Development team.
  • Bug Triage: Drive and manage the bug triage process, evaluating issues and documenting their replication patterns.
  • SDLC & Quality: Participate in the overall software development life cycle, ensuring high quality, scalability, and robust solutions.
  • Reporting: Keep management, customer support, and product teams updated on product delivery and quality status.

Market Trend: Supply Chain & Tech Integration

Modern e-commerce giants like Lenskart rely heavily on automated warehouses and highly optimized supply chain software. An "L1 Support Engineer" in a plant environment is the nervous system of the company—identifying bugs in real-time before they halt manufacturing. This role gives freshers deep exposure to Warehouse Management Systems (WMS), high-volume database troubleshooting (MySQL), and Java-based enterprise architectures, setting a strong foundation for a future as a Core Backend Developer.

Eligibility & Technical Requirements

Shift Commitment: Candidates must be absolutely comfortable working a permanent night shift (9 PM to 6 AM) at the assigned plant locations.

Basic Java MySQL Web Applications Bug Triage Communication
  • Education: B.Tech in Computer Science or MCA.
  • Experience: Freshers or candidates with up to 1 year of experience.
  • Core Tech: Strong grasp of basic Computer Science fundamentals, basic Java, and MySQL queries.
  • System Knowledge: Basic understanding of Web Applications and how they interact with databases.
  • Soft Skills: Excellent communication skills to interface between non-technical operations staff and highly technical core developers.

Expert Preparation Guide for Lenskart L1 Support

1. Java & Exception Handling

As an L1 Support engineer, your primary task is diagnosing errors. Master Exception Handling in Java (try-catch, stack traces) and know how to read server logs to identify where a web application is breaking.

2. MySQL Database Querying

Warehouse issues often require quick database checks. Be highly proficient in writing SELECT queries with complex JOINs, WHERE clauses, and understanding basic database indexing to retrieve data quickly.

3. The "Translation" Skill

The JD specifically asks you to translate functional issues from warehouse staff to core developers. Practice your communication: How would you explain a "Database Deadlock" to a non-technical warehouse manager? Or how would you explain an "Order Sync Failure" to the backend dev team?

Recommended Extra Activities

  • Learn Bug Tracking Tools: Familiarize yourself with Jira or Bugzilla. Knowing how to correctly format a "Bug Ticket" (Steps to reproduce, Expected vs Actual result) is crucial for the triage process.
  • Web Application Architecture: Understand the basic MVC (Model-View-Controller) architecture so you know which part of the code to investigate when an issue is reported.
