Specialist - AWS Data and Analytics

PwC Advisory - Building Trust in Society and Solving Important Problems

Location: Gurugram, India | Specialism: Data, Analytics & AI

Drive Overview

At PwC, our people in data and analytics focus on leveraging data to drive insights and make informed business decisions. We are looking for a motivated and enthusiastic AWS Specialist with 0-1 years of experience to join our Cloud Engineering team in Gurugram. This purpose-led and values-driven role offers an excellent opportunity to build expertise in cloud technologies while working alongside experienced cloud professionals to support infrastructure operations, monitoring, and basic automation on Amazon Web Services (AWS).

Experience Level 0 - 1 Years (Fresher)
Primary Stack AWS, Python, Shell
Line of Service Advisory

Your Role & Responsibilities

This is a foundational cloud engineering role where you will support the deployment, monitoring, and security of applications running on enterprise AWS infrastructure.

  • Cloud Infrastructure: Support infrastructure management using core AWS services such as EC2, S3, IAM, VPC, RDS, and CloudWatch.
  • Monitoring & Triage: Monitor system health, performance, and availability and escalate issues as required.
  • Automation: Contribute to automation and scripting tasks using basic Python, Shell scripting, or AWS tools.
  • Security & DR: Assist in implementing security best practices via IAM, and support backup, recovery, and disaster recovery activities.
  • Collaboration: Collaborate with cross-functional teams to support project delivery and maintain technical documentation and knowledge repositories.
  • Continuous Learning: Stay updated with emerging AWS services and cloud technologies in a dynamic advisory environment.

Market Trend: Cloud Advisory & Data Analytics

The convergence of Cloud Computing and AI is redefining how global enterprises operate. "Big 4" firms like PwC are scaling their Data, Analytics & AI practices rapidly to help clients migrate to secure, automated cloud environments. As an AWS Specialist, gaining hands-on expertise in IaC (Infrastructure as Code) and Python scripting will place you in one of the most resilient and highly compensated career trajectories in the IT consulting space.

Eligibility & Technical Requirements

AWS (EC2, S3, IAM, VPC) Python / Shell / PowerShell Linux / Windows OS CloudWatch Monitoring DevOps (Git/Docker) Bonus
  • Education: B.E./B.Tech/MCA/BCA/B.Sc. (Computer Science/IT) or equivalent qualification. (MBA/BE candidates are also eligible).
  • Experience: 0-1 years of experience. Freshers with relevant internships or academic projects in cloud tech are highly preferred.
  • Core Cloud Skills: Basic understanding of AWS Cloud services and cloud computing fundamentals/networking concepts.
  • Scripting: Basic understanding of scripting using Python, Shell, or PowerShell.
  • Certifications: AWS Cloud Practitioner certification (or willingness to obtain one) is highly preferred.
  • Bonus Skills: Exposure to DevOps tools such as Git, Jenkins, Docker, or Terraform is a strong advantage.

Expert Preparation Guide for PwC AWS Role

1. Master AWS Fundamentals

The JD specifically lists EC2, S3, IAM, VPC, RDS, and CloudWatch. You must know what each service does. Be prepared to explain how you would configure a basic VPC with public and private subnets, and how IAM policies secure an S3 bucket.

2. Scripting & Automation

Expect questions on Python or Bash scripting. You may be asked how to write a simple Python script (using Boto3) to list all EC2 instances in an account, or how to write a Bash script to automate log backups.

3. The Big 4 "Consulting" Mindset

PwC values communication, empathy, and "Accepting Feedback." Prepare STAR (Situation, Task, Action, Result) method answers demonstrating your collaborative approach, learning agility, and how you handle complex troubleshooting scenarios in a team.

Recommended Extra Activities

  • Get Certified: If you haven't already, studying for the AWS Certified Cloud Practitioner exam will cover 90% of the theoretical knowledge needed for this interview.
  • Build a Mini-Project: Host a static website on an S3 bucket or deploy a simple Python web app on an EC2 instance. Share the GitHub repository link on your resume.
  • Learn Basic Terraform: Since Terraform is a preferred skill, spending an hour learning how to provision an EC2 instance via code will make you stand out massively.
